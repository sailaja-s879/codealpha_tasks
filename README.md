# CodeAlpha Task 2: Stock Portfolio Tracker

## Description
Stock Portfolio Tracker is a simple Python application that calculates the total investment value of a stock portfolio using predefined stock prices and user-entered quantities.

## Features
- Displays available stock names and prices.
- Accepts stock names and quantities from the user.
- Calculates the investment value of each stock.
- Displays the total portfolio investment.
- Saves portfolio details in a CSV file.
- Handles invalid stock names and quantities.

## Technologies Used
- Python
- Dictionaries
- Loops and conditional statements
- User input and output
- Basic arithmetic
- CSV file handling

## How to Run
1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Open a terminal in the project folder.
4. Run the following command:

   `python stock_portfolio_tracker.py`

5. Enter a stock name, such as `AAPL` or `TSLA`.
6. Enter the quantity you want to track.
7. Type `done` to display the portfolio summary.

## Sample Stock Prices
| Stock | Price |
|---|---:|
| AAPL | $180 |
| TSLA | $250 |
| GOOGL | $150 |
| MSFT | $420 |
| AMZN | $190 |

## Output
The program displays the investment value for each selected stock and the total investment value. It also saves the portfolio details in `stock_portfolio.csv`.

## Note
The stock prices are predefined sample values and are not live market prices.
