
# Task 4: Basic Chatbot

## Description
A simple rule-based chatbot developed using Python.
It responds to user messages using predefined replies.

## Features
- Greets the user
- Responds to "How are you?"
- Handles goodbye messages
- Displays a default reply for unknown inputs
- Runs continuously until the user types "bye"

## Technologies Used
- Python

## Concepts Used
- if-elif-else statements
- Functions
- While loops
- User input and output
- String handling

## How to Run
1. Download basic_chatbot.py.
2. Open it in Python or VS Code.
3. Run the program.
4. Enter messages and type "bye" to exit.
